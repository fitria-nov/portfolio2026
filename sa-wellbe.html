Overall Description

System Purpose

Aplikasi Well-Be hadir sebagai respons terhadap kebutuhan kritis dalam perawatan lansia penderita demensia dan Alzheimer. Sistem yang ada saat ini seringkali reaktif, bukan proaktif. Well-Be dirancang untuk tidak hanya memantau secara fisik melalui GPS tracking, tetapi juga memberikan dukungan emosional melalui fitur linimasa memori digital.

Operating Environment

Mendukung minimal Android 8.0+ dan iOS 12.0+. Membutuhkan koneksi internet aktif untuk sinkronisasi data lokasi dan notifikasi real-time dari perangkat smartwatch yang terhubung via Bluetooth/Wi-Fi.

UC-01: Melacak Lokasi Secara Real-time

Critical Function
Primary Actor
Keluarga, Pengasuh
Summary
Melacak koordinat pasien secara langsung menggunakan GPS dari smartwatch yang terintegrasi.
Basic Flow
  1. Pasien memakai smartwatch yang berstatus terhubung.
  2. Pengasuh membuka halaman pemantauan di aplikasi seluler.
  3. Sistem menarik data koordinat secara berkala.
  4. Peta interaktif menampilkan pin lokasi pasien saat ini.
  5. Jika pasien keluar dari zona aman (Geofence), sistem langsung mengirim push-notification darurat.

UC-02: Mengelola Memori (Linimasa)

Therapy
Primary Actor
Keluarga, Pasien
Summary
Fasilitas unggah dan kelola foto/video momen bahagia sebagai instrumen terapi ingatan pasien.
Basic Flow
  1. Anggota keluarga masuk ke modul 'Memories'.
  2. Memilih fungsi unggah (foto/video/teks).
  3. Menambahkan deskripsi dan tanggal momen tersebut.
  4. Data tersimpan dan disinkronisasi ke perangkat pasien.
  5. Pasien dapat menelusuri memori secara kronologis di aplikasinya.
